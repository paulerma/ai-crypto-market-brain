AI CRYPTO MARKET BRAIN PRO 3.3 — MODO SIMPLE

OBJETIVO
La pantalla principal responde primero cuatro preguntas:
1) ¿Qué escenario domina en el horizonte elegido: SUBIDA, LATERAL o BAJADA?
2) ¿Con qué probabilidad estimada del modelo?
3) ¿En qué ZONA de precio podría moverse el activo si ese escenario ocurre?
4) Si rompe al alza o a la baja, ¿qué nivel confirma el movimiento y dónde queda un stop de referencia?

RESUMEN FÁCIL
- SUBIDA: probabilidad estimada + zona proyectada.
- LATERAL: probabilidad estimada + zona proyectada.
- BAJADA: probabilidad estimada + zona proyectada.
- Se resalta el escenario de mayor probabilidad, aunque una advertencia separada indica si la calidad OOS del modelo todavía es débil.

STOP CONDICIONAL
- Plan alcista: exige ruptura por encima de estructura reciente + buffer ATR.
- El stop se coloca por debajo de la zona rota / ATR.
- Plan bajista: exige pérdida de estructura reciente + buffer ATR.
- El stop/invalidez queda por encima de la zona rota / ATR.
- Los objetivos NO se modifican para fabricar un R:R favorable. Si la proyección deja poco espacio, la app lo advierte.

PROYECCIÓN DE PRECIOS
No se muestra un precio exacto como garantía. Se muestran zonas construidas a partir del rango estadístico de volatilidad del horizonte:
- zona de SUBIDA,
- zona LATERAL más estrecha alrededor del precio,
- zona de BAJADA.

GRÁFICO SIMPLE
- Velas + EMA 200 + soporte/resistencia.
- Línea de confirmación de subida y stop condicional.
- Línea de confirmación de bajada y stop/invalidez condicional.
- Arrastrar = mover; rueda/trackpad = zoom; doble clic = restaurar.

AVANZADO
Las pestañas restantes conservan la validación OOS, scanner, multi-timeframe, indicadores, backtest y gestión de riesgo para auditoría; no es necesario entenderlas para leer el resumen principal.

IMPORTANTE
- Precio LIVE y proyección son cosas distintas: LIVE se actualiza aprox. cada 10 s; el modelo usa la última vela cerrada.
- Una probabilidad del modelo no es una probabilidad garantizada de ganancia.
- El escenario dominante puede mostrarse aunque el filtro de calidad indique NO OPERAR.
- En spot, la parte BAJADA es especialmente útil como alerta/salida; abrir un SHORT requiere un instrumento que permita posiciones cortas.
