AI CRYPTO MARKET BRAIN PRO · FASE 3.5 RADAR DE VELAS

OBJETIVO
- Mantener el análisis cuantitativo detrás, pero mostrar delante solo lo útil:
  SUBIDA / LATERAL / BAJADA, probabilidad, zona de precio, en qué ventana de
  velas podría empezar el cambio, confirmación y stop condicional.

TEMPORALIDADES ESTÁNDAR
1m · 5m · 15m · 1h · 4h · 1D · 1W · 1M

RADAR DE VELAS
- Analiza horizontes acumulativos +1, +2, +3, +5 (según timeframe).
- No afirma que una vela exacta sea segura. Busca la primera VENTANA estable
  entre horizontes, por ejemplo +2 a +3.
- Exige persistencia del escenario o evidencia fuerte para evitar un único
  horizonte aislado.
- Cada horizonte conserva validación walk-forward, calibración y filtros OOS.
- Si la evidencia no alcanza, dice "sin ventana fiable".

IMPORTANTE SOBRE 1M
Binance ofrece velas mensuales, pero incluso BTC tiene relativamente pocas
observaciones mensuales desde su listado. El gráfico 1M funciona, pero esta app
NO fuerza un modelo ML mensual directo cuando no hay muestra suficiente. Para
predicción probabilística larga, usar 1W/1D y 1M como contexto de ciclo.

TIEMPO REAL
El precio LIVE sigue separado del modelo. La señal se recalcula con la última
vela cerrada; se muestra aproximadamente cuándo cerrará la vela actual para que
sepas cuándo tiene sentido actualizar la IA.

RIESGO
Los stops son condicionales: solo aplican después de que el precio confirme el
nivel indicado. No son garantía de limitar exactamente la pérdida por slippage,
gaps o movimientos rápidos.

LIMITACIÓN CLAVE
Ningún modelo puede saber con certeza qué hará la siguiente vela. El objetivo es
mejorar calibración, selectividad y transparencia, no fabricar probabilidades
altas. Un resultado "sin ventana fiable" es una salida válida y deseable.
